# 授权账本频率分析（2026-09-25，supervisor 新角色提案的输入）

- 性质：只读统计，**不是门证据**，不构成任何授权、裁定或规则；归类由分析会话逐条人工判断，边界条目可能有争议。
- 数据源：`docs/authorizations.md` 2026-07-30…2026-09-24 共 137 条（不含 2026-09-25 起新增的条目）。
- 逐条表：`docs/evidence/authorization-ledger-stats-2026-09-25.csv`（序号 = 不计 2026-09-25 起新增条目时账本自上而下第 n 条，0 = 2026-09-24「用户签发 §5 执行信封」；列含日期、工作项组、
  标题、来源分组、触发原因、原话形态、代录角色、是否事后异地转录、条目字数、原话摘录）。
- 产出会话：用户直接指挥的 Claude Code 会话（未以任何角色命令开工），2026-09-25；零测试、零消耗。

## 1. 口径

触发原因（为什么要找用户）：

| 代号 | 名称 | 判据 |
|---|---|---|
| DIR | 方向/范围决策 | 项目方向、立项、范围取舍、设计选项 |
| LIFE | 暂停/恢复/关闭 | 工作项生命周期与验收 |
| FACT | 事实认定/纠正 | 用户事实认定或账本归因纠正 |
| META | 流程规则修改 | COORD 协调批次、chore 细则等规则本身的修改 |
| ESC | 流程强制拍板 | 规则规定必须由用户决定的节点（退修上限二选一、复核超限、例外、history 同意、放行次序等） |
| GO | 单次运行放行 | 逐次 Play / trial / attempt 放行 |
| ENV | 首次签发信封 | 一个阶段的执行信封或阶段执行授权 |
| ADD | 追加额度/越界补批 | 已签信封之外的追加或补批（次数、文件、安装） |
| OPS | 操作杂事 | 推送、存储位置、执行顺序、归档、杀进程等 |

来源四组：需要用户判断 = DIR+LIFE+FACT；流程自身产生 = META+ESC；放行与额度 = GO+ENV+ADD；操作杂事 = OPS。

原话形态：短确认（「授权」「好的」「签发」一类，不含新内容）｜点选选项（AskUserQuestion 标签或打字选字母）｜
自己写的实质内容（用户引入了问题里没有的内容或决定）｜转述或无原话。

## 3. 代录与转录

- 代录角色：接受 66、构思 31、监督/协调类会话 24、辅助 12、其他助手 3、复核 1。
- 事后异地转录 21 条（15%）：授权发生在另一会话（多为实现会话；实现角色对账本只读），事后由接受角色（11）或辅助角色（10）转录。
- 转述条目 6 条、无原话行 1 条、归因纠正 1 条（原记为「用户六点裁定」的内容实为接受角色的审查意见，已作废保留）。
- 非正式的「监督/方向顾问」会话：8 条由用户指派的监督/方向顾问会话代录，全部是 COORD 流程批次（008、009、009 修订 B、011、
  012×2、013、014），其中 COORD-008/013/014 账本标题明写「不经接受轮」；另 3 条由构思会话兼任监督视角代录。该会话形态在
  `docs/roles/`、`AGENTS.md`、两份 workflow 与 `tools/check_role_writes.py` 中都没有定义，没有自己的写入白名单；本分析会话在
  2026-09-25 暂停 `P1-ENG-FAST-001` 时也只能借用 `--role acceptance` 的写入口径。

## 4. 与 supervisor 新角色相关的观察（供构思参考，不是结论）

1. 已有需求：监督/方向顾问会话实际在运行，提出并推动了多个流程批次，但没有角色细则、写权限和轮次纪律，写入只能借用其他角色口径，
   角色边界的审计线索因此变模糊。
2. 用户负担的主要来源不是方向判断（28%），而是流程自身（34%）与放行/额度（27%）；点头型 69%、推荐项采纳 91%。
3. 候选减负方向（均未提案、未授权；均触及工作流基础设施，需用户直接授权的协调批次）：
   退修第 2 次二选一设默认；信封预留小额余量；低风险选项推荐项默认生效、用户只在反对时开口；实现会话可写「待确认」账本条目。
4. 需守住的红线：授权与信封只能来自用户原话并逐字入账（`AGENTS.md`「工作流轨道路由」「共享状态更新」）；任何「由 supervisor
   代为决定」的设计都要说明它与这一条如何兼容，不能变成新的授权来源。

## 5. 局限

- 触发原因与形态为人工归类，同一条目可能同时具有多种性质，只取主因。
- 推荐项比例只统计选项标签带推荐标记的选择；无标记的选择不计入分母。
- 原话字数由正则自动抽取，含选项标签文字，个别自写长句可能漏抽，只作量级参考。
- 账本只记「关键授权」，不等于用户与各会话的全部交互。
