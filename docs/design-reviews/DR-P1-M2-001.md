## Metric validity and ceiling analysis

**天花板结构核实**。benign 载体的几何天花板是实测事实：qual-2
（20 Hz、D1、协议无效但数值可读）`c_geom = 1.000000`——D1 条件下
`C_track|geom ≡ C_track`，条件化完全惰性，场景本身零几何区分度。这与
设计 §6"B0 无遮挡应≈100% 是 sanity check 而非成绩"的定位一致，且
v0.3.7 已把该风险预登记给 RATE-003 用速度阶梯正面处理；区分度负担因此
**全部**落在 D2 与 5 Hz 档上（D2@5Hz 帧间位移 21.75–25.52 px，为参考框
min-side 43 px 的 50.6–59.4%，位移压力真实存在）。该结构本身可接受。

**主指标条件化于受处理变量（阻断发现 B1 的依据）**。代码核实
`CoverageEvaluator.cs`：`GeometricallyVisible` 由 15 采样点对**当前相机
视锥**的 `WorldToViewportPoint` 检查 + 遮挡射线共同决定（L615-636）；
`geometricDuration` 仅在该帧可见时累计（L413-419）；
`c_track_given_geom = trackingDuration / geometricDuration`（L782）。
相机由云台驱动、云台由被测闭环驱动、闭环节拍即处理变量（帧率）——
**主端点的分母是 post-treatment 量**。RATE-002 困难场景实测印证该通道
真实存在：三个 follow run 的 `c_geom = 0.612626/0.610449/0.610445`，
其中含云台跟随漂移框导致目标出视锥的部分。benign 场景 D1 下该危害
惰性（分母恒满），但在 D2——恰是全部区分度所在——若 5 Hz 档漂移导致
指向失败，分母坍缩会**抬高** `C_5`，从而：

- 掩盖真实效应 → 假 `NO_EFFECT_DETECTED_MIDBAND` 或假 `CEILING(D2)`
  （后者直接误诊为 `H1_FALSIFIED_CEILING_AT_D2` 并"返回设计"）；
- 制造 `RATE_EFFECT_INVERTED` 伪象（该路已 DR referral，可接受）；
- **最危险**：正效应成立路径不设防——例如
  `C_geom,20=0.99 / C_geom,5=0.70`、`C_t|g,20=0.85 / C_t|g,5=0.78`
  给出 Δ=0.07 的"干净"contrast established，而无条件 `C_track` 差为
  0.84 vs 0.55；论文主数字严重低估效应且无任何旗标提示指向失败是
  主要机制。现行设计对此的唯一防线是 Failure modes 里的"若实测
  [C_geom] 显著下降…分开报告"——**"显著下降"是未定义比较**，恰是
  acceptance round 1/2 在其他各处系统清除的表述类别（"明显低于/显著
  背离"）。按本仓库自己的接受标准，这必须在数据产生前钉成数值旗标。

**处分函数其余部分**：六值封闭枚举、floor 先于 ceiling 的判序、
`ladder_premise_violated`/`dr_referral_required`/异质性限定、θ=0.05
实际意义阈值定位、type-7 分位数钉死——逐条核对无歧义，可按字面执行。
H2 内部标定点（`8.0/20 = 2.0/5 = 0.4 m/帧`精确对称）是低成本高价值的
模型检验，描述性定位正确。

## Findings

### Blocking

- **B1 — 主端点分母是受处理变量，防线是未定义比较。**
  `C_track|geom` 的分母（几何可见时长）经"帧率→追踪→云台→视锥"闭环
  依赖处理变量；5 Hz 档指向失败时分母坍缩抬高 `C_5`，可假装天花板、
  掩盖效应，且正效应成立路径上无任何旗标暴露"指向失败为主机制"，
  论文主数字会系统低估效应。现行唯一防线"`C_geom` 显著下降→分开报告"
  无数值定义。**要求**：数据产生前以接受角色裁定的数值把它钉死——
  (i) `p1-rate3-decision/v1` 增加逐 run `c_geom`、`c_track`（无条件）
  字段；(ii) 新增预注册旗标（建议
  `CGEOM_DIVERGENCE_FLAG := ∃i, |C_geom(20,s*_i) − C_geom(5,s*_i)| >
  θ_geom`，θ_geom 建议取 0.05，与 θ 同级，数值由接受角色数据前冻结）；
  (iii) 绑定解释规则：旗标为真时 `dr_referral_required := true`，任何
  率效应/零效应/天花板结论必须同时报告无条件 `C_track` 配对差，且不得
  把条件化 Δ 单独作为效应量；旗标定义与字段进入 decision schema 哈希链。
- **B2 — D2/6.0 m/s 配置按字面无法通过提案引用的包络审计。**
  环周期门 [30,45] s 与干扰机会 tick 预算均由配置速度导出，D2 必然
  `ENVELOPE_OUT_OF_BOUNDS`，工具还钉死 D1 配置路径；"预期零违规"不可
  满足，审计范围未定义。**要求**：接受角色在 batch 2 之前显式分治——
  速度无关门（斜距/off-nadir/p05 像素/路线合法性）对 D2/6.0 配置必须
  重跑并通过；速度导出门（环周期、干扰机会）对难度配置显式改为记录性
  重算（记录 D2 实际值与 D1 基准差异）或显式豁免并说明理由；工具的
  配置路径参数化属实现细节，但豁免/记录的语义必须先入设计，不得由
  实现者自行改判。
- **B3 — 三相位 × "标定 2 次"不可执行，配对初始化锚点未成文。**
  现有 HOLD 机制每会话一个 `s*`，2 次标定会话无法产出 3×2 个
  (difficulty, phase) 的冻结参考框；且"同一 (difficulty, phase) 下
  两率共享字节相同冻结框"这一配对公平锚点未写成 binding 条款。
  **要求**：接受角色在 batch 2 之前裁定标定机制（多相位标定新机制/
  每相位一次共 6 次/逐 run HOLD 冻结的等价替代），同步重算会话预算并
  对照 0a（超出"约 16 次"即需用户重新确认）；无论选哪种，必须成文：
  同一 (difficulty, phase) 的 5/20 Hz 两 run 从同一份 SHA-256 绑定的
  冻结参考框初始化。
